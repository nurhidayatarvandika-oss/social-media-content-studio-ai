# Publishing approval checklist

- [ ] Correct account and platform
- [ ] Final video/image file checked
- [ ] Title/caption/description checked
- [ ] Thumbnail/cover checked
- [ ] Subtitles and accessibility checked
- [ ] Links and CTA tested
- [ ] Claims and source notes verified
- [ ] Music, footage, image, and font rights verified
- [ ] Consent and privacy checked
- [ ] Sponsorship/affiliate/AI disclosures checked where applicable
- [ ] Date, time, and timezone confirmed
- [ ] Owner approved this exact publishing action
- [ ] Publishing result/URL recorded after confirmation
