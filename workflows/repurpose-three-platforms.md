# Workflow: Repurpose Three Platforms

## Steps
1. Identify approved source asset and core message
2. Extract facts, story beats, and reusable footage
3. Create YouTube version and metadata
4. Create Facebook-native version and community copy
5. Create TikTok-native version and discovery language
6. Check each version stands alone and preserves context
7. Run rights and QC checks
8. Obtain per-platform approval

## Completion criteria
- Required deliverables are present.
- Unknowns and risks are visible.
- Human approval is recorded before external publication.
